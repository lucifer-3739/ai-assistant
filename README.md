# AURA OS — AI-Native Voice-Controlled Computer Agent

Instructions to run the program and description of features are available inside the `aura-os` folder.

## Quick Start
1. Configure your Gemini API Key in `aura-os/apps/agent/.env`.
2. Run the `aura-os/start-aura.bat` script.

Refer to `run.txt` or `aura-os/README.md` for complete documentation.
